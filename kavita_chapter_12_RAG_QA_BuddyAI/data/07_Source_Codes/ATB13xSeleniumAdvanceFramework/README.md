# 01 — Selenium framework repo

**Leave empty** to let the ingester shallow-clone
`https://github.com/PramodDutta/ATB13xSeleniumAdvanceFramework` into a `repo/` subfolder at
run time, **or** drop the framework source directly into this folder to ingest it as-is.

**Ingested by:** `qabuddy.ingest.repositories` (code-aware chunking by class/method).

**Accepted:** any text source (`.java`, `.xml`, `.properties`, `.md`). Binary artifacts
(`target/`, `.jar`) are skipped automatically.
